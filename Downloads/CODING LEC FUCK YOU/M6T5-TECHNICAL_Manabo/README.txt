# Bouquet Company

## Overview

Bouquet Company is product to give customers their preferred scent of choice. The website was created as a responsive HTML, CSS, and JavaScript project.

## Features

- Homepage with bouquet product information
- Contact page with a form
- Responsive layout for mobile and desktop screens
- Mobile navigation menu
- Dark mode button
- Form validation using JavaScript
- Visitor settings saved using localStorage
- Live website hosted through InfinityFree

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser localStorage
- InfinityFree

## Setup

To run the project locally:

1. Download or clone the project files.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or a web browser.
4. Make sure the `css`, `js`, and `assets` folders remain in the same project folder.
