Static Site Deployment Readiness Checklist

Code & Assets

[ ] All HTML, CSS, and JavaScript syntax validated without errors

[ ] Console logs, debugger statements, and commented-out dead code removed

[ ] All internal links, anchor tags, and navigation paths verified

[ ] All relative asset paths (images, fonts, scripts, stylesheets) verified case-sensitively for Linux servers

[ ] All external third-party API keys, analytics tags, and form endpoints pointed to production

[ ] Cross-browser and responsive mobile viewport testing completed

Configuration & Routing

[ ] Default entry point file (index.html) placed in the correct document root directory

[ ] Custom 404 and 500 error pages configured

[ ] WWW vs. non-WWW canonical domain redirects configured

[ ] HTTP to HTTPS forced redirect active

[ ] Clean URL rewrites or trailing-slash rules tested in server configuration

Performance & SEO

[ ] CSS and JavaScript files minified and bundled

[ ] Images compressed and served in modern formats (WebP/AVIF) with width/height attributes

[ ] Browser caching headers and Gzip/Brotli compression enabled

[ ] Page titles, meta descriptions, Open Graph tags, and favicons present on all pages

[ ] robots.txt and sitemap.xml verified and accessible at root

Security

[ ] SSL/TLS certificate installed, valid, and free of mixed-content warnings

[ ] Directory browsing disabled

[ ] Sensitive files (.git, .env, README, source maps, build configs) excluded from upload

[ ] Standard security headers (CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy) configured

[ ] File and folder permissions verified (644 for files, 755 for directories)

Staging & Backup

[ ] Full backup of existing production files and server configuration archived

[ ] Rollback archive and restore procedure verified

[ ] DNS TTL lowered ahead of cutover (if migrating domains or hosts)

[ ] Post-deployment smoke test plan ready for live verification
